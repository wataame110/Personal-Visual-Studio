# 医療向け機能・プロファイル管理

## 医療機関モードの概要

医療モードは一般モードの基礎技術に加え、以下を提供します。

- 成人人体の詳細な3D再現（着衣のない人体モデルの編集）
- 胸部・腹部・四肢・顔面の細部編集
- 女性外性器（恥丘・陰核亀頭・陰核包皮・大陰唇・小陰唇・外陰前庭・尿道口・膣口・会陰）の独立編集
- 男性外性器（陰茎体・亀頭・冠状縁・包皮・陰嚢）の独立編集
- 陰茎の湾曲の局所的形状変形（左右・上下・開始位置・範囲・屈曲角度）
- 体毛の表示・脱毛デザイン（密度・長さ・毛色・残す範囲）
- 計測（二点間距離・角度）・注釈
- 施術案の複数保存・ビフォーアフター比較（カメラ同期付き）
- パラメータごとの情報区分（写真確認／実測・計測／手動設定／システム推定）

### 医学上の位置づけ（重要）

- 本ツールは**視覚的説明・形状比較・デザイン検討の支援**を目的とします
- 医学的な診断や治療結果の確定的予測を行うものではありません
- 画面上の計測値は**参考値**です。校正済みの実測値として扱わないでください
- 画面上で設定した湾曲角度などの参考角度と、実測された角度は区別してください
- 脱毛シミュレーションの表示は医療者が設定した条件に基づく参考シナリオであり、
  施術回数と減毛率を固定的に対応させたものではありません
- 外性器の編集機能は身体的特徴と医療上の必要性に基づくものであり、
  利用者の性自認などから身体構造を自動的に決めつけません（基礎体型は「カスタム」で両方の部位を編集可能）
- 人体の解剖学的形状は医学的監修を受けていない近似モデルです（`docs/LIMITATIONS.md` 参照）

## 認証システム（二画面認証）

### 画面構成

1. **第1認証画面**：ユーザーID＋ログインパスワード。一致した場合のみ第2画面へ進みます
2. **第2認証画面**：使用許可パスワード。一致した場合のみ医療画面が表示されます

- 第1認証を経ずに第2画面へアクセスした場合は第1画面へ戻されます
- 第2認証を経ずに医療画面へアクセスした場合も認証画面へ戻されます
- ログアウトすると両方の認証状態が解除されます
- 認証状態はブラウザのタブごと（sessionStorage）に保持され、タブを閉じると解除されます

### セキュリティ上の重要な制約

この認証は**公開JSONとクライアント側JavaScriptによる簡易アクセスゲート**です。

- JSONファイルを取得すれば誰でも資格情報を読み取れます
- JavaScriptの照合処理は技術的に回避可能です
- サーバー側認証・多要素認証と同等のセキュリティは**提供しません**

したがって：

- **開発・検証版では実患者情報を扱わないでください**
- 実患者の機密データを公開配信アセットやJSONに含めないでください
- 開発用の検証資格情報と実運用の秘密情報を混同しないでください
- 実運用（実患者情報の取り扱い）には、別途適切な認証・アクセス制御・データ保護
  （サーバー側認証、暗号化、アクセスログ等）の導入が**必須**です

## プロファイル管理（開発者向け）

### 設定ファイル

`public/auth/profiles.json` を直接編集できます。変更は再読み込み後の認証判定に反映されます。

```json
{
  "version": 1,
  "profiles": [
    {
      "id": "MED-001",
      "userId": "user001",
      "loginPassword": "user001",
      "permitPassword": "user001",
      "enabled": true,
      "role": "medical",
      "version": 1
    }
  ]
}
```

### パスワード変更

1. `public/auth/profiles.json` を開く
2. 対象プロファイルの `loginPassword` / `permitPassword` を変更する
3. ファイルを保存して再デプロイ（ローカルの場合は再読み込み）

### プロファイルの無効化

`enabled` を `false` に設定すると、そのプロファイルはログインできなくなります。

### 増枠（30→50→100…）

```bash
node tools/generate-profiles.mjs 50 public/auth/profiles.json
```

- 既存プロファイルの資格情報は保持されたまま新しい枠が追加されます
- ログイン画面や認証ロジックの変更は不要です
- 一般ユーザーがサイト上でアカウントを新規登録する機能はありません

## 出力・レポート

- 施術案は「比較案」として複数保存でき、`.pvsproj` に含まれます
- 計測結果・注釈もプロジェクトファイルに保存されます
- 説明用の画像は「画像出力」で任意の角度から作成できます
