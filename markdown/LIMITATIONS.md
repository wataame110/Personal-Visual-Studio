# 既知の制約・未検証事項

本ドキュメントは、実装済み機能の制約と未検証の領域を正確に示すものです。

## 写真編集エンジン（主エディタ）

- 編集は元写真の画素を基準とした領域限定処理です。**AI画像生成（インペインティングGAN・拡散モデル等）は搭載していません**。除去・補完は周囲画素からの反復拡散充填による近似であり、大面積や複雑な模様では質感が平坦になります。
- 髪型の「形」の変更は局所変形（リキファイ）による手動編集です。別の髪型写真からの自動転写（HairFastGAN等の研究実装）は**未搭載**です。
- 洋服の写真試着（CatVTON/IDM-VTON等の仮想試着AI）は**未搭載**です。衣服領域の色調変更・形状変形は可能ですが、別衣服の立体的な着用合成はできません。
- 領域分割は MediaPipe selfie multiclass モデルによる自動分類で、背景・髪・体肌・顔肌・衣服・その他の6クラスです。複数人・複雑な背景では精度が低下します。ブラシによる手動補正で対処してください。
- 編集解像度は長辺1400pxに制限されます（ブラウザ内CPU処理の実用速度優先）。
- 施術後の外観シミュレーションは視覚的参考画像であり、医学的な結果予測ではありません。

## 3D人体モデルの精度

- 編集用人体モデルはプロシージャル生成による**近似モデル**です。医学的監修を受けた解剖学的モデルではありません。`models/cc0/` のCC0 GLBは参考・インポート用資産であり、現行のパラメータ編集メッシュを置換するものではありません。
- 顔の特徴（目・鼻・口など）は実在感のあるパラメトリック形状ですが、本人への高精度な再現性は**未検証**です。検証には専用の評価データと専門家による評価が必要です。
- 外性器の形状は解剖学的文献に基づく監修を受けておらず、視覚的説明支援のための近似です。臨床品質としては表示しません。
- 手・足は簡略化された形状です（指のモデルは未実装）。
- 皮膚の質感は手続き生成のバンプ/粗さマップによる近似です。実写同等の質感ではありません。
- 本人再現は正面写真のランドマーク・色情報からの初期フィッティング＋手動補正の方式であり、写真に写らない奥行き・背面・側面の形状は未確認のままです。「写真確認／実測／手動設定／システム推定」の区分を確認してください。
- 現行の編集用メッシュは写実的人体系アセット（MakeHuman等）への置換前のプロシージャルモデルであり、実写のような外観には達していません。

## 写真解析

- MediaPipe による正面写真のランドマーク検出を実装しています。
- 検出精度は写真の品質・角度・照明に依存します。誤検出は手動補正で対処してください。
- 正面1枚の写真からは奥行き情報を取得できません。側面形状は推定されません。
- 写真からの体型推定は肩幅・骨盤幅の比率など限定的です。
- 複数枚写真や動画からの3D再構成は未実装です。

## 衣服・試着

- 衣服は体型に追従するパラメトリックな簡易モデルです。
- 2D商品写真からの3D衣服復元・生地の物性シミュレーション（ドレープ等）は行いません。参照画像のテクスチャ投影のみ対応します。
- 実際のサイズ・フィット感の予測ではありません。

## 体毛・脱毛

- 体毛は1本1本の描画ではなく、密度に応じた半透明パッチによる近似表現です。
- 脱毛範囲の指定は矩形パラメータによる簡易マスクです（自由形状ペイントは未実装）。
- 脱毛部位は現在「恥骨領域」のみ対応しています。

## 計測

- 画面上の計測値は3Dモデル空間の参考値であり、校正済みの実測値ではありません。
- 実測スケールとの整合は身長入力に依存します。

## 認証

- 医療モードの認証は開発・検証用の簡易アクセスゲートです。実患者情報の保護には使用できません（`markdown/MEDICAL.md`）。
- 本番運用にはサーバー側認証等の別途実装が必須です。

## 保存・出力

- `.pvsproj` は JSON 形式です。大きな元画像を含めるとファイルサイズが大きくなります。
- GLB への再読み込みは「参照モデルの表示」であり、GLB から編集パラメータへ逆変換は行いません（再編集は .pvsproj を使用）。
- 画像出力は最大 4096×4096 px です（GPUメモリ制約への配慮）。

## パフォーマンス

- 画質「低（軽量）」モードでメッシュ分割数を削減していますが、実際の低性能端末での動作検証は限定的です。
- Web Workers によるバックグラウンド処理の移譲は未実装です（現状はメインスレッドで十分軽量に動作）。
- PWA によるオフライン永続化は未実装です（ブラウザキャッシュの永続性は保証されません）。

## ブラウザ互換性

- WebGL 非対応環境では3D機能を利用できません（起動時に通知します）。
- iOS Safari 等のモバイル環境での動作検証は限定的です。

## 未実装の項目

- ボーン・スケルトンによるポージング（姿勢パラメータによる前傾/後傾のみ対応）
- 複数写真・3Dスキャンデータからの再構成
- 自由形状の脱毛マスクペイント
- IndexedDB への自動保存（現状は明示的なファイル保存）
- レポート（説明資料）の PDF 出力
