# Personal Visual Studio

高精度3D人物モンタージュ・人体再現・医療美容シミュレーション・バーチャル試着の統合Webアプリケーションです。

ブラウザ内ですべての処理が完結し、写真・3Dモデル・作業データが外部サーバーへ送信されることはありません。

## 主な機能

### 一般モード
- 顔・頭部・全身のパラメトリック3D再現（連続曲面のロフトメッシュ）
- 部位別・左右独立の詳細編集（目・鼻・口・眉・耳・体型・四肢など）
- 正面写真1枚からの初期ガイド生成（MediaPipe による端末内解析・手動補正可）
- 髪型・髪色・部分カラー・グラデーション
- 衣服の試着（トップス・アウター・パンツ・スカート・ワンピース・靴・帽子）
- メガネ・アクセサリーの配置
- 3Dモデルの360度回転・拡大縮小・視点プリセット・部位フォーカス
- GLB 出力・再読み込み、PNG/JPEG/WebP 画像出力
- `.pvsproj` 専用プロジェクト形式による完全な再編集
- Undo/Redo・比較案（案A/B/C）の保存・複製・並列比較

### 医療機関モード（認証制）
- 解剖学的な部位別編集（胸部・腹部・四肢の細部、女性・男性外性器）
- 陰茎の湾曲（左右・上下・開始位置・範囲・屈曲）の局所的形状変形
- 計測（二点間距離・角度）・注釈・施術案の複数保存
- 体毛・脱毛デザイン（密度・長さ・毛色・残す範囲のマスク）
- パラメータごとの情報区分表示（写真確認／実測／手動設定／システム推定）

## 重要な注意事項

- 本アプリの医療機能は**視覚的説明の支援**を目的としており、医学的な診断や治療結果の確定的予測を行うものではありません。
- 医療モードの認証は**開発・検証用の簡易アクセスゲート**です。実患者情報の保護には使用できません（詳細は `docs/MEDICAL.md`）。
- 開発・検証版では**実患者情報を使用しないでください**。
- 人体の解剖学的形状は医学的監修を受けたものではなく、近似モデルです。

## クイックスタート

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 自動テスト
npm run build      # 本番ビルド（dist/）
```

医療版プロファイルの生成・増設：

```bash
node tools/generate-profiles.mjs 30 public/auth/profiles.json   # 30枠
node tools/generate-profiles.mjs 50 public/auth/profiles.json   # 50枠へ増設
```

MediaPipe モデルの配置（写真解析を使う場合）：

```bash
node tools/fetch-models.mjs
```
