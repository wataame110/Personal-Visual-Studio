# 基本操作マニュアル

## 写真編集（主エディタ）

トップページの「一般モード」または医療機関ログイン後のホームから開きます。
取り込んだ写真を原本として、**指定した領域だけ**を編集します。領域外の画素は元写真のまま保持されます。

### 手順

1. 「写真を開く」で本人の写真を読み込みます（処理速度のため長辺1400pxに縮小されます）
2. 「領域を自動分割」で髪・顔（肌）・体（肌）・衣服のマスクを自動生成します（端末内処理）
3. 左パネルで編集対象の領域を選びます。マスクは「範囲を追加／除去」ブラシで手動補正できます
4. 右パネルで操作を適用します
   - **色変更**：色相・彩度・明度（髪色・衣服色の変更など）
   - **スムージング**：肌の質感を自然に均します
   - **明暗調整**：明るさ・コントラスト
   - **除去・補完**：マスク内を周囲の画素から充填（体毛・シミの除去など。医療モードでは衣服領域にも適用可能）
   - **局所変形**：画像上をドラッグして部分的に形状を変形（リリースで確定）
5. 「並列比較」タブでBefore/Afterを並べて確認できます
6. PNG/JPEG/WebPで出力、または「保存 (.pvsproj)」で作業状態を保存できます

- 一般モードでは衣服領域の除去（脱衣）はできません。
- 除去・補完はAI生成ではなく周囲画素からの近似充填です。大面積では質感が平坦になります。
- 「3Dモンタージュ編集を開く」から、写真を使わない3D人物作成へ移動できます。

## 3Dモンタージュ画面構成

- **上部ツールバー**：ファイル操作（新規・開く・保存）、Undo/Redo、写真取込、GLB読込、出力（GLB・画像）、UIモード・画質の切替、ヘルプ
- **左パネル**：部位ツリー（表示/非表示・ロック切替）
- **中央**：3D編集ビュー（比較時は左右2画面）
- **右パネル**：選択部位の詳細パラメータ／全身設定／髪／衣服／（医療：計測・脱毛）
- **下部**：編集履歴・比較案・注釈・状態表示

## 3D人物モデルの作成手順

### 完全手動モンタージュ（写真・AI不要）

1. 一般モードを開始します
2. 右パネル「全身」タブで身長（実測値）・皮下脂肪・筋肉・姿勢・基礎体型を設定します
3. 左の部位ツリーで部位を選び、右パネルのスライダーで形状を調整します
4. 「髪」「衣服」タブで外観を整えます
5. ツールバー「保存 (.pvsproj)」で作業データを保存します

### 写真からの半自動作成

1. ツールバー「写真取込・解析」を開きます
2. 正面を向いた写真（JPEG/PNG/WebP）を選択します
3. 「解析を実行」を押します（端末内で処理され、外部送信されません）
4. 検出されたランドマーク（青：顔・緑：姿勢）を確認し、誤検出はドラッグで補正します
5. 実測の身長を入力し、「ガイドをモデルに反映」を押します
6. その後は手動編集で細部を仕上げます

写真から取得できるのは正面から見える位置・比率と、肌色・髪色の概算です。
奥行き・体積など写真に写らない情報は推定されず、背面・側面の特徴は未確認のままです。
抽出された色は照明の影響を受けるため、部位の色調編集で手動調整してください。

#### 元写真との比較
写真を取り込んだ後、3Dビュー左下のコントロールで以下が使えます。

- **写真を重ねる**：元写真を3Dモデルに半透明で重ね、輪郭のずれを確認
- **透明度スライダー**：重ね合わせの濃さを調整
- **写真を並列表示**：元写真を3Dビューの右側に表示（ランドマーク点つき）

比較してずれが大きい部位は、部位ツリーから選択して詳細パラメータで手動補正してください。
解析に失敗しても「解析せず手動で編集」で作業を継続できます。

## 編集の基本操作

| 操作 | 方法 |
| --- | --- |
| モデルの回転 | 左ドラッグ |
| 拡大・縮小 | ホイール / ピンチ |
| パン | 右ドラッグ / Shift+ドラッグ |
| 部位の選択 | モデル上をクリック / 部位ツリー |
| 視点の切替 | ビュー左上のボタン、またはキー `1`〜`9` |
| 部位へフォーカス | 部位ツリーでクリック |
| 元に戻す | `Ctrl+Z` |
| やり直し | `Ctrl+Y` / `Ctrl+Shift+Z` |
| ヘルプ | `F1` |

数値はスライダーだけでなく直接入力も可能です。
「詳細」UIモードでは位置オフセット・回転・スケールなど高度なパラメータが表示されます。
UIモードを切り替えても作業データは失われません。

## 左右独立編集と設定コピー

目・眉・耳・乳房・腕・脚・陰唇などは左右が独立した部位です。
片方の設定を反対側へコピーするには、右パネル下部の「この設定を〜へコピー」を使います。
左右は自動では対称化されません。

## 比較（ビフォー・アフター）

1. 下部パネルで名前を付けて「現在の状態を保存」（案A・案B…）
2. 各案の「比較」ボタンで、編集中モデルと並列表示
3. 「カメラ同期」をオンにすると両画面の視点が揃います

## 保存・再開

- **`.pvsproj`**：完全な再編集用（モデル・パラメータ・髪・衣服・比較案・注釈・計測・カメラ位置・元写真を含む）
- **GLB**：完成3Dモデルの交換・閲覧用（他のglTF対応ビューアで開けます）
- **画像出力**：PNG/JPEG/WebP。解像度・背景色・透過背景を設定可能

ファイルが破損している場合はエラーメッセージが表示され、編集中のデータは失われません。

## FAQ・トラブルシューティング

アプリ内のヘルプ（`F1`）に FAQ を収録しています。

- **画面が真っ暗**：WebGL が無効な可能性。ブラウザを更新・変更してください
- **動作が重い**：ツールバーの画質を「低（軽量）」へ切替
- **写真解析が失敗する**：モデルファイル未配置の可能性。`node javascript/tools/fetch-models.mjs` を実行
- **保存したファイルが開けない**：形式バージョンの非互換。エラーメッセージを確認
