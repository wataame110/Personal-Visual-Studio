# CC0 human base mesh

`human-base-rigged.glb` is a CC0 human base mesh released by Innerscene,
built from MakeHuman/MPFB CC0 body, rig, and skin assets.

- Source page: https://www.innerscene.com/tools/library/3d-parts/human-base-mesh-with-editable-53-bone-rig-8e7c8ab1
- Download endpoint: https://www.innerscene.com/api/library/human-base-mesh-with-editable-53-bone-rig-8e7c8ab1/download
- Format: glTF Binary (GLB), version 2
- Size: 4,994,640 bytes
- SHA-256: `7135e03b6259e970458deff3e0458610914d7c35164cae12611101361e4a5749`
- Retrieved: 2026-10-27

The asset is kept as an optional high-detail reference/import asset. The
application's editable body remains the parameterized Three.js mesh so that
body-part selection, gender templates, clothing enforcement, medical parts,
undo/redo, and deterministic GLB export continue to work without a network
request.
